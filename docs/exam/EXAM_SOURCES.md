# Exam sources, structure and publication rights — ChemLab 6.5

Updated 2026-10-20 (remediation). A paper is takeable only when it reaches every state in `REQUIRED_STATES` (`src/exam/catalog.js`):
`SOURCE_VERIFIED` → `OWNER_ATTESTED` → `CONTENT_TRANSCRIBED` → `ANSWER_KEY_VERIFIED` → `SCORING_VERIFIED` → `UI_TESTED`; `READY_FOR_OWNER_RELEASE` is derived, never declared. Papers are never generated by AI and never assembled from the Practice bank.

## 0. Authorization basis

The project owner stated: *“Tôi đã được cấp phép sử dụng các đề thi, kể cả đề của Đồng Nai hay các đơn vị bên ngoài.”* The licence documents are confidential and were **not seen** by the agent. ChemLab therefore records `rights: { basis: 'owner_attestation', status: 'OWNER_ATTESTED', documentSeenByAgent: false }` — not “independently verified”. No personal data from any licence is stored. Public release remains the owner's decision.

## 3. How to add a paper

1. Obtain the original from the issuing authority (Bộ GD&ĐT, Cục QLCL, Sở GD&ĐT website or an official file the owner provides). Record URL/date; keep the SHA-256 of the file in the paper header.
2. Create `src/exam/papers/<id>.js` like `tham-khao-2025-hoa.js`: exact transcription, figures cropped from the original into `src/exam/papers/assets/<id>/`, `solution.official` truthful, chapter tags `internal`, no invented levels.
3. Type the official key a second time into `OFFICIAL_KEYS` in `scripts/test-exam-papers.mjs`; add recomputation for numeric answers.
4. Write `docs/exam/papers/<id>.md` (per-question checklist). Add states to the catalog only as each is reached; add a browser journey before `UI_TESTED`.
5. Run `npm run check:exam`, `npm run check:browser`, `npm run check:a11y`.
