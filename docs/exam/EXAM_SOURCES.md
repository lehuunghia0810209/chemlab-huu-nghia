# Exam sources, structure and publication rights — ChemLab 6.5

Checked 2026-10-20. Rule: ChemLab publishes a paper's questions only when (1) the source is official, (2) permission to copy/redistribute is confirmed in writing or by an explicit licence, (3) the transcription and (4) the answer key were verified. Until then a paper is listed as **metadata only** with a link to its source. Exam papers are never generated by AI and never assembled from the Practice bank.

Publicly available ≠ licensed: none of the pages carries a licence for redistribution, and Vietnamese law excludes from copyright only legal and administrative documents, which is not an established status for exam papers. ChemLab therefore treats the rights as unconfirmed.

## 3. How an owner adds a licensed paper

1. Obtain written permission (or a licence) covering copying the questions into ChemLab; record it in the table above.
2. Create `src/exam/papers/<id>.js` following `fixture-kiem-thu.js` (kind `official-reference` or `official-exam`, full 18/4/6 structure, `dataVersion: 1`), transcribing the original exactly. Mark each `solution.official` truthfully; mark `meta.status: 'verified'` only after a teacher checked the chapter/level tags.
3. In `src/exam/catalog.js`, set `load`, `license: 'licensed'`, `publication: 'published'` and `verification: { transcription: 'verified', answerKey: 'verified', by: '<name>', date: '<date>' }` only after a second person compared the transcription and the key with the original.
4. Run `npm run check:exam` (validates structure and keys) and `npm run check:browser`.

## 4. Fixture mode (testing only)

The fixture is visible only in `vite dev` or after `localStorage.setItem('chemlab-exam-fixtures', '1')`. It is labelled “không phải đề chính thức” everywhere it appears and is not evidence that exam content is complete.
